# pl_mpeg

Single-header MPEG-1 video / MP2 audio decoder and MPEG-PS demuxer, used to play
optional high-resolution replacements of the cinematics (`video/hd/*.mpg`).

- **Origin:** [pl_mpeg](https://github.com/phoboslab/pl_mpeg) by Dominic Szablewski, vendored unmodified.
